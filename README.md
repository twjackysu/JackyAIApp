# JackyAIApp

![GitHub commit activity](https://img.shields.io/github/commit-activity/m/twjackysu/JackyAIApp)

JackyAIApp is a collection of AI-powered apps — English learning, Taiwan stock analysis, portfolio tracking, data analysis, and a few utilities — served from one site. This is a private side project, but contributions from anyone are welcome.

## 🌐 Live Demo

🔗 [https://apps.jacky-studio.com/](https://apps.jacky-studio.com/)

## ⚠️ Disclaimer

The data generated by this application is entirely produced by generative AI. As such, we do not guarantee the accuracy of the data. Please use the information provided by this application at your own risk.

## 🛠️ Tech Stack

### Backend
- **.NET 10 Web API** with Swagger documentation
- **Entity Framework Core 10** with SQL Server
- **Azure App Service** hosting (Linux), behind Cloudflare
- **Azure Key Vault** for secret management
- **OpenAI integration** via Betalgo.Ranul.OpenAI package
- **Anthropic integration** via the official `Anthropic` SDK

### Frontend
- **React 19** with TypeScript strict mode
- **MUI v9** for UI components with dark theme support
- **Redux Toolkit** with RTK Query for state management
- **React Router v7** for navigation
- **Vite** as build tool

### AI & APIs
- **OpenAI gpt-6-luna** for text generation and analysis
- **Claude Haiku 5.5** for the Finance AI assistant (with the remote `tw-stock` MCP server)
- **OpenAI Whisper** for speech-to-text transcription
- **Azure AI Speech** for text-to-speech (OpenAI TTS as fallback)
- **Taiwan Stock Exchange (TWSE) / TPEx Open API**, Yahoo Finance, FundRich (基富通), SEC EDGAR for financial data

### Database & Infrastructure
- **Azure SQL Database** (migrated from Cosmos DB)
- **Azure Blob Storage** for listening-exam images and chat attachments
- **Azure Key Vault** for secrets
- **GitHub Actions** for CI/CD
- **Google OAuth** for authentication

## 🚀 Features

The home page (`/`) is the portal for switching between apps.

### 📚 English Coach (`/english/...`)
- **Dictionary**: bilingual definitions, synonyms/antonyms, example sentences, audio pronunciation
- **Personal repository** of saved words and word packs
- **Exams**: cloze, translation (AI-graded), conversation (scenario-based, voice input), sentence formation, listening, reading comprehension, writing, dictation
- **Daily challenge**, **spaced-repetition review** (SM-2), streak / XP / weekly report / leaderboard

### 📊 Stock Intelligence (`/finance`)
- **AI assistant** for Taiwan stock questions
- **Quantitative analysis**, **AI trend analysis** (short/medium/long term), **daily market AI summary**

### 💼 Wealth Portfolio (`/portfolio`)
- Snapshot-based holdings: TW/US stocks, funds, cash, liabilities, real estate
- Total return including dividends, XIRR, drawdown, benchmark comparison

### 📈 Data Analysis (`/data-analysis`) & Data Dashboard (`/dashboards`)
- Query and summarize SQL Server / Azure Data Explorer sources or uploaded files; ask questions in natural language
- Save results as dashboard widgets, shareable privately, with chosen users, or publicly

### 🧰 Utilities
- **PDF Unlocker & Compressor** (`/pdf`)
- **Folder Slideshow** (`/slideshow`) — runs entirely in the browser
- **Job Finder** (`/jobs`) — listings from 104 and Cake
- **Connected Services** (`/connectors`) — OAuth connections to Atlassian / Microsoft / Google

AI-powered features share a per-user daily usage budget; there is no payment.

## 🏗️ Architecture

### Frontend Structure
```
jackyaiapp.client/src/
├── apis/           # RTK Query API slices
├── [Feature]/      # Feature-based components
├── components/     # Reusable UI components
├── redux/          # Store configuration
├── auth/           # Authentication components
└── constants/      # App configuration
```

### Backend Structure
```
JackyAIApp.Server/
├── Controllers/    # API controllers
├── Services/       # Business logic
├── Data/           # EF Context, Models, Migrations
├── DTO/            # Data transfer objects
├── Prompt/         # AI prompt templates
└── Common/         # Error handling, response factory
```

## 🔐 Authentication & Security

- **Google OAuth** authentication only

- **HTTPS** enforced in all environments
- **Comprehensive input validation** on all endpoints
- **No local user registration** - OAuth only

## 🚀 Getting Started

### Prerequisites
- .NET 10 SDK
- Node.js 20.19+
- SQL Server (local or Azure)
- Azure Key Vault access (for production)

### Local Development

1. **Backend Setup**
   ```bash
   cd JackyAIApp.Server
   dotnet restore
   dotnet run
   ```

2. **Frontend Setup**
   ```bash
   cd jackyaiapp.client
   npm install
   npm run dev
   ```

3. **Database Migration**
   ```bash
   cd JackyAIApp.Server
   dotnet ef database update
   ```

### Environment Configuration
- Configure Azure Key Vault connection
- Set up OpenAI and Anthropic API keys
- Configure Google OAuth credentials

## 📦 Deployment

- **CI/CD**: GitHub Actions — every push to `master` (a merged PR included) builds, tests and deploys; pushes that touch only `.agent/**` or `*.md` are skipped
- **Target**: Azure App Service (Linux)
- **Process**: Build → Test → Publish → Deploy
