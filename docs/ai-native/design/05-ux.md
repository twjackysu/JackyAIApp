# 05 — UX

> 沿用現有設計語言（MUI v9、深色主題、app 顏色、`@/components/hints` 不用 hover-only tooltip）。手機優先檢查。

## 1. 全站助理（Studio AI）

- **入口**：每頁右下角圓形按鈕（避開既有 floating back button，手機上在底部安全區上方）＋ 鍵盤 ⌘K／Ctrl+K。未登入點下去 → 「登入後可使用 AI 助理」+ 登入按鈕。
- **外觀**：桌機右側抽屜（寬 440，可拉到 640），手機全螢幕 sheet。標題列：「Studio AI」+ 目前頁面 chip（例：「在：Data Analysis」）+ 歷史 + 新對話 + 關閉。
- **歡迎畫面**：依目前頁面給 3 個建議（在 /english → 「查一個單字並加入單字庫」；在 /portfolio → 「總結我的投資組合」；在 /data-analysis → 「這份資料有哪些欄位？」），下方列出「我能用的工具」：本站 + 已連線 connector 的 icon 列，點了到 /connectors。
- **工具進度**：每個工具一列 `ToolActivity`：connector icon、工具顯示名稱、轉圈→✓（耗時）或 ⚠（錯誤一句話）。可展開看參數與結果摘要（給好奇的人，預設收合）。
- **卡片**：工具結果的 card 直接出現在訊息流中，訊息文字在卡片下方。
- **確認卡（ApprovalCard）**：
  ```
  ┌ 需要你的確認 ─────────────────────────────┐
  │ 📘 本站・單字庫   加入單字                  │
  │   word: serendipity                          │
  │ [允許]  [拒絕]                               │
  └──────────────────────────────────────────────┘
  ```
  多個呼叫一起出現時逐條列出、各自決定，最後一個「送出」。外部 connector 的寫入卡片加上 connector 名稱與「這個動作會在 ○○ 上執行」。對話被外部內容「污染」時，卡片下方說明「這段對話讀過外部內容，寫入動作一律需要確認」。
- **錯誤人話**：沒設定 API key →「AI 助理尚未設定（管理者需要設定 Anthropic API key）」；connector 需重新授權 → 卡片附「前往重新連線」；額度 → 既有 `UsageLimitModal`。

## 2. /data-analysis 的 AI 對話

- 最上方，和 /finance 一樣的一行框（Launcher），placeholder「問問你的資料，例如：去年各月營收趨勢，畫成折線圖」，標明這是對話。
- 展開後與 Finance 同一套面板；page context 帶目前資料源，所以「這份資料」指的是畫面上選的那份。
- 圖表卡片用 Data Analysis 既有的 viz renderer（`DataAnalysis/viz`），右上「加到 dashboard」按鈕（走同一個確認流程或直接開既有 `AddToDashboardDialog`）。
- 下方原本的 Schema／摘要分析（含「問 AI」）／明細 tabs 不動。

## 3. Connectors（/connectors 演進）

- 頁首：「Connectors — 讓 AI 用你的工具」，一句說明 + 「新增 MCP server」主按鈕。
- 三個區塊：
  1. **已連線**：卡片格狀，每張：icon、名稱、狀態 chip（已連線／需要重新授權／錯誤／停用）、工具數（Auto/Confirm/Disabled 計數）、最後測試時間。點開 → 詳情。
  2. **目錄**：分類 chip（本站、資料、開發、生產力、金融），每張「連線」按鈕。既有的 Google／Microsoft／Atlassian 在「生產力」分類，沿用現有 `ConnectorCard` 的流程（含自填 client 設定）。
  3. **進階**：既有的「複製 token」放在既有卡片的進階區（不移除，避免退化）。
- **新增 MCP server 對話框**（三步）：
  1. 名稱 + URL → 「偵測」：顯示偵測結果（免認證可直接連／需要 OAuth（AS 名稱、支援 CIMD/DCR）／需要 API key）。
  2. 認證：依偵測結果顯示對應表單（OAuth → 「前往授權」；API key → header 名 + 值；手填 client id/secret 收在「進階」）。
  3. 完成：自動測試連線，列出工具與預設權限，可直接調整 → 「完成」。
- **詳情頁**（抽屜）：URL、認證方式、授權範圍（scope）、最後錯誤、[測試連線]、[重新授權]、[停用]、[移除]；工具表：名稱、說明、效果（讀／寫／破壞性）、權限三段切換（自動／需確認／停用）。
- portal：Connectors 重新在首頁 portal 顯示（原本因 Google scope 權限問題隱藏），描述改成「讓 AI 使用你的工具與服務」。若 Jacky 不想顯示，`apps.tsx` 一行改回。

## 4. 無障礙與手機

- 所有 icon-only 按鈕用 `ActionTooltip`（自帶 aria-label）。
- 確認卡按鈕至少 44px 高；鍵盤可操作（Tab 順序：允許 → 拒絕）。
- ⌘K 開啟後焦點進輸入框，Esc 關閉並把焦點還給原處。
