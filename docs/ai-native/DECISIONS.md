- **D-013（2026-10-24 04:15，Jacky 建議，不改主線）知識庫（KB）connector 列為 M4 延伸**：不自架 vector DB，讓使用者接自己的 KB。(1) Atlassian 直接用官方 Atlassian Remote MCP Server 放進目錄（OAuth，順便當 M3 MCP OAuth 的真實案例）；(2) AWS Bedrock Knowledge Bases 原生 connector：使用者填 region、KB ID、IAM 金鑰（加密存），唯讀工具 `kb_search` 呼叫 Retrieve API；(3) PostgreSQL + pgvector 原生 connector：連線字串、表／欄位、embedding 模型（查詢必須用與入庫相同的模型 embedding），唯讀 `kb_search`。連線資料一律走 SafeHttp／SSRF 規則（pgvector 的主機也要擋內網）。

- **D-015（2026-10-24）共用 chat 前端放 `src/components/aiChat`**（從 `Finance/components/aiAssistant` 純搬家，`localStorage` key `aiAssistant.keepPasteFormatting` 保留不改，使用者設定不會遺失）；通用的 `signInAndComeBack` 從 `Finance/utils` 搬到 `src/utils/signIn.ts`。

- **D-030（2026-10-24 12:30）沒有 OAuth 之前，偵測到 401 的伺服器回 `auth: apiKey`**：讓使用者貼 token／API key。OAuth（PRM/CIMD/DCR/PKCE）仍在 M3。

- **D-034（2026-10-24 14:20）MCP OAuth 成為 client 的順序：DCR → CIMD → 手填**（design/03 §5.2 原本 CIMD 優先，規格也偏好 CIMD）：CIMD 要授權伺服器在使用者登入當下經 Cloudflare 抓我們的 metadata 文件（main site 只收 Cloudflare 流量、可能有 bot 防護），失敗只會出現在對方頁面；DCR 失敗發生在我們的請求裡，可以給人話。伺服器沒有 registration_endpoint 才用 CIMD。使用者自己填了 client id 時一律用它。本機（localhost）沒有 CIMD。
- **D-035（2026-10-24 14:20）PRM 的 `resource` 接受同源的上層路徑**（RFC 9728 要求完全相同，但 Notion 等伺服器常回 origin）：與官方 TypeScript SDK 的 `checkResourceAllowed` 相同——scheme／host／port 相同，伺服器路徑在 resource 路徑之內；送給授權伺服器的 `resource` 用 PRM 寫的值。

- **D-037（2026-10-24 14:20）目錄加入 Notion、Linear（OAuth）**：兩者都是 Streamable HTTP、支援 DCR 與 PKCE（官方文件）。session 連不到外網，**沒有實測**；合併後請 Jacky 在 production 試一次（FOR_JACKY 7）。
- **D-038（2026-10-24 14:20）Portfolio 工具是唯讀、預設自動**：使用者問自己的資產時才會被呼叫；送給模型的是本站已估值的數字（不含交易明細）。想更保守的人可以在 Connectors 把它設成「需確認」或停用。
- **D-039（2026-10-24 16:00）Google 日曆是「本站工具」型的原生 connector**（`ISiteTool`，connector 是 `site`，Connectors 頁「本站功能」下的「Google 日曆」組），不另做一種 connector 列：權限沿用現成的 site 設定，token 用既有 Google 帳號連線（scope 原本就有 `calendar.readonly`）。為了不讓行事曆邀請（別人能寫的字）繞過 taint，`AiToolDescriptor` 加 `OutsideText`：本站工具的結果含外部文字時，跟外部 connector 一樣讓這輪之後的寫入一律先問。沒連線時不是錯誤，回連結卡到 /connectors。
- **D-040（2026-10-24 16:05）MCP step-up：403 `insufficient_scope` → 把 scope 併進登入、標 NeedsAuth、保留 token**（其他工具照用），重新授權時一起要；scope token 只收 RFC 6749 NQCHAR、合計最多 1000 字。SDK 的例外沒有 header，所以 `McpToolClient` 用 DelegatingHandler 記下拒絕的 `WWW-Authenticate`。
- **D-041（2026-10-24 16:20）確認卡的「以後直接執行」只給本站工具的寫入、而且這段對話沒讀過外部內容**：外部 connector 的工具名是每輪的 `m1__…`，要到 Connectors 頁調；無法復原的永遠要問；讀過外部內容後伺服器反正都會問。勾了且按允許才設成自動（同 `PUT tool-permissions`）。

- **D-043（2026-10-24 16:10）MCP OAuth 回呼帶 `kind=mcp`**：/connectors 對 AI connector 用中文說明結果與下一步；帳號連線（Google／Microsoft／Atlassian）的英文訊息不變（頁面既有測試鎖住）。
